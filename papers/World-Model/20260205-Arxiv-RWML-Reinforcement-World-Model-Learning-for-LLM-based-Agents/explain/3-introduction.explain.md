## 论文引言解析

### 1. 问题背景与领域动机
*   **客观事实**：大型语言模型（LLMs）在语言相关任务（如问答、代码生成、多步推理）上取得了显著成功。
*   **领域动机**：基于LLM构建能够与现实环境交互、完成长期任务的自主智能体，已成为一个重要的研究方向。
*   **核心问题**：尽管LLMs具备强大的语言和推理能力，但在需要**预测行动后果**和**适应环境动态变化**的智能体场景中，其表现往往不佳。
*   **作者观点**：这凸显了预训练获得的 **“语言能力”** 与智能体所需的 **“智能体智能”** 之间存在根本区别。

### 2. 现有工作的局限或缺口
作者指出了两个主要研究方向及其各自的局限性：

**A. 训练决策智能体的方法：**
1.  **模仿学习（SFT）**：依赖人类专家或更强LLM生成的高质量演示数据。**局限**：此类数据收集成本高，难以规模化。
2.  **强化学习（RL）**：直接从任务成功与否的最终奖励中学习。**局限**：在复杂环境中设计有效的任务成功奖励函数，需要大量人工专业知识，同样限制了可扩展性。

**B. 训练世界模型的方法：**
1.  **分离式世界模型**：训练一个独立的世界模型，用于支持推理时算法（如MCTS）。**局限**：需要训练/推理多个模型，计算成本高。
2.  **联合学习世界模型与策略**：在单一模型中联合学习。**局限**：现有方法（如使用SFT预测下一状态）严重依赖来自专家或更强LLM的高质量标注数据（轨迹或合成数据）。此外，SFT方法追求**词元级保真度**，可能导致模型崩溃，且不一定保证语义等价性。

**总结缺口**：缺乏一种**可扩展的、自监督的**方法，来提升单一LLM智能体的世界建模能力，从而弥合其预训练目标与长期、动态的智能体任务需求之间的差距。
