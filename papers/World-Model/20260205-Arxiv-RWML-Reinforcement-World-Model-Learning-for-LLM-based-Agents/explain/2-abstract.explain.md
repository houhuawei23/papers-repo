## 论文摘要解析

### 研究问题与动机
基于大语言模型（LLM）的智能体在预测动作后果和适应环境动态方面存在困难，这凸显了为其构建世界模型能力的必要性。本研究旨在通过自监督方法，提升LLM智能体对文本化环境动态的理解和模拟能力。

### 核心方法要点
- **方法名称**：提出**强化世界模型学习**（Reinforcement World Model Learning, RWML），一种自监督方法。
- **核心机制**：利用**模拟到现实的差距奖励**，为基于LLM的智能体学习**以动作为条件**的文本状态世界模型。
- **对齐目标**：在预训练的嵌入空间中，促使模型生成的**模拟下一状态**与环境观察到的**实际下一状态**保持一致，从而鼓励内部世界模拟与真实环境动态的一致性。
- **方法优势**：相较于追求逐词复现的“下一状态词元预测”，RWML更关注语义等价性，提供了更鲁棒的训练信号，并且在经验上比“LLM即法官”的方法更不易受到奖励欺骗的影响。

### 主要结论与量化结果
- **评估基准**：在ALFWorld和$\tau^{2}$ Bench基准上进行评估。
- **性能提升**：尽管是完全**自监督**的，RWML方法相比基础模型取得了显著增益。
- **组合效果**：当与任务成功奖励结合使用时，RWML在ALFWorld和$\tau^{2}$ Bench上分别比直接使用任务成功奖励的强化学习（RL）方法高出**6.9**和**5.7**个点。
- **对标表现**：同时达到了与使用专家数据训练方法相当的性能。
