## 小节解析：2 Agent Model

### 小节角色概括
该小节是全文的核心模型定义部分，旨在提出一个受人类认知系统启发的智能体模型，该模型由视觉（V）、记忆（M）和控制器（C）三个组件构成，为后续章节详细描述各组件及其集成方式奠定基础。

### 关键技术点与定义
1.  **整体模型架构**：智能体由三个紧密协作的组件构成：
    *   **视觉模型（V）**：压缩高维感官输入（如图像帧）为低维表征代码。
    *   **记忆模型（M）**：基于历史信息，预测未来的表征代码。
    *   **控制器模型（C）**：仅基于V和M产生的表征来决定采取何种动作。

2.  **VAE (V) 模型（2.1）**：
    *   **目的**：学习对每一时刻高维观察输入（通常是2D图像帧）的抽象、压缩表征。
    *   **技术选择**：使用变分自编码器（VAE）。
    *   **输出**：将图像帧压缩为小的潜向量 \(z\)。
    *   **图示**：Figure 5（VAE流程图）用于说明V模型的工作原理。

3.  **MDN-RNN (M) 模型（2.2）**：
    *   **目的**：压缩时间信息，预测未来的潜向量 \(z\)，作为环境的预测模型。
    *   **技术特性**：为处理环境的随机性，模型预测概率密度函数 \(p(z)\) 而非确定值。
    *   **具体建模**：RNN建模条件概率 \(P(z_{t+1}\;|\;a_{t},z_{t},h_{t})\)，其中 \(a_t\) 是t时刻动作，\(h_t\) 是RNN的隐状态。
    *   **输出形式**：将 \(p(z)\) 近似为高斯混合分布，RNN输出该分布的参数。
    *   **关键参数**：采样时可调整温度参数 \(\tau\) 以控制模型不确定性，并提及这对后续训练控制器有用。
    *   **技术名称**：混合密度网络（MDN）与RNN的结合（MDN-RNN）。
    *   **图示与类比**：Figure 6（MDN-RNN结构图）说明其工作原理；Figure 7（SketchRNN示例）作为MDN-RNN在序列生成问题上的应用类比。

4.  **Controller (C) 模型（2.3）**：
    *   **目的**：决定行动策略以最大化智能体在环境推演中的期望累积奖励。
    *   **设计原则**：有意保持C模型简单、小巧，并与V、M分开训练，使智能体的主要复杂性集中于世界模型（V和M）。
    *   **具体形式**：单层线性模型。公式 (1) \(a_{t}=W_{c}\;[z_{t}\;h_{t}]\;+b_{c}\) 定义了其映射关系，其中 \(W_c\) 和 \(b_c\) 是权重和偏置，输入是 \(z_t\) 与 \(h_t\) 的拼接向量。
    *   **参数规模**：C的参数数量远少于V和M。

5.  **V、M、C的集成与工作流程（2.4）**：
    *   **交互流程**：Figure 8（智能体模型流程图）具体说明了三者与环境交互的顺序：V处理原始观察得到 \(z_t\)；C接收 \(z_t\) 与 \(h_t\) 的拼接，输出动作 \(a_t\)；M接收 \(z_t\) 和 \(a_t\) 更新其隐状态为 \(h_{t+1}\) 供下一时刻使用。
    *   **控制器（C）的训练策略**：
        *   **动机**：由于V和M可通过反向传播高效训练，且C参数极少，这允许采用非常规方法（如进化策略）训练C，以应对信用分配困难的强化学习任务。
        *   **具体算法**：选择协方差矩阵自适应进化策略（CMA-ES）来优化C的参数。
        *   **实施方式**：在单机多CPU核上并行运行多个环境推演以进化参数。
