# U-Net 网络结构（依据 Ronneberger 等，arXiv:1505.04597）

本文档根据论文《U-Net: Convolutional Networks for Biomedical Image Segmentation》的叙述，概括其 **编码器—解码器式全卷积分割网络** 的结构要点；图示以论文图 1（最低分辨率 32×32 的示意）为准。

---

## 概述

U-Net 是一种专为生物医学图像分割设计的全卷积网络架构。其核心创新在于对称的“U”形结构，结合了上下文信息（通过收缩路径）与精确定位信息（通过扩展路径），使其在仅有少量标注样本的情况下也能实现高质量的分割。

## 1. 总体思想

- **任务**：像素级语义分割（生物医学场景下常为二分类或多类实例/语义标签），输出与“定位”一致的分割图。
- **骨架**：在 **全卷积网络（FCN）** 思路上扩展——用 **收缩路径** 提取多尺度上下文，用 **对称扩展路径** 恢复分辨率，二者通过 **跳跃连接** 融合高分辨率特征，形成 **U 形** 布局，故称 U-Net。
- **与滑动窗口 patch 分类的对比（论文动机）**：全图（或大块）前向一次，减少重叠 patch 带来的冗余计算；通过编码器加深获得上下文，通过解码器与 skip 恢复细粒度定位，缓解“大感受野 vs 高定位精度”的矛盾。

---

## 2. 收缩路径（Contracting Path，左侧 - 编码器）

典型 **卷积网络** 结构，作用是 **捕获上下文**：

| 环节 | 说明 |
|------|------|
| 基本单元 | 重复两次 **3×3 卷积**（**无填充**，unpadded），每次卷积后 **ReLU**。 |
| 下采样 | **2×2 最大池化**，步长 2。 |
| 通道数 | 每经一次下采样，**特征通道数加倍**。 |

语义上等价于逐级提高抽象层次、扩大有效感受野，同时空间分辨率降低。

遵循典型的卷积网络架构：

- 每一级包含**两次重复的 3x3 卷积**，每个卷积后接一个**修正线性单元（ReLU）**。
- 在每一级的最后，应用一个**步长为 2 的 2x2 最大池化层**进行下采样，将特征图尺寸减半。
- 每次下采样后，**特征通道数加倍**。
- 该路径通过逐步降低空间分辨率、增加通道数，有效扩大了感受野，以捕获全局上下文信息。

---

## 3. 扩展路径（Expansive Path，右侧 - 解码器）

与收缩路径 **大致对称**，作用是 **提高输出分辨率** 并把上下文传回高分辨率层：

| 环节 | 说明 |
|------|------|
| 上采样 | 对特征图上采样后接 **2×2 卷积**（文中称 **up-convolution / 上卷积**），将 **通道数减半**。 |
| 融合 | 与收缩路径 **同尺度** 的特征图 **拼接（concatenation）**；因无填充卷积会“吃掉”边界，来自编码器的特征需 **裁剪（crop）** 后与解码器侧对齐。 |
| 细化 | 拼接后再做两次 **3×3 卷积 + ReLU**。 |

**论文强调的一点**：扩展路径中同样使用 **大量特征通道**，使上下文信息能传播到高分辨率层——这与“解码器很窄”的设计形成对比，是 U-Net 相对朴素 FCN 解码器的一个特点。

用于恢复图像细节和空间分辨率：
- 每一步开始于对特征图进行**上采样**（如使用反卷积或上池化），随后是一个 **2x2 卷积（上卷积）**，将特征通道数减半。
- 关键操作：将上采样后的特征图与**收缩路径中对应层级的特征图进行拼接（Concatenation）**。
    - 由于每次卷积会丢失边界像素，需要对收缩路径的特征图进行**裁剪**，以确保维度匹配。
- 拼接后，再次应用**两次 3x3 卷积**，每个卷积后接一个 ReLU。
- 这种跳跃连接设计允许网络在恢复空间分辨率时，同时利用深层的高级语义特征和浅层的低级空间细节特征。

---

## 4. 输出头

- 最后一层为 **1×1 卷积**：将每个位置的 **64 维特征向量**（论文默认配置下）映射到 **类别数 K**。
- 整网共 **23 个卷积层**。
- **无全连接层**，全卷积端到端训练。

- 在最后一层，使用一个 **1x1 卷积**将特征向量（64维）映射到所需的类别数量（K）。
- 1x1 卷积起到了逐像素分类的作用，将每个像素的特征向量转换为类别预测。


---

## 5. 分辨率与边界

- **无填充卷积** 导致每级卷积后特征图略小于输入；因此输出分割图相对输入在边界上 **收缩** 一个 **恒定的边界宽度**——论文在训练策略上据此处理 tile 与标签对齐。
- 拼接前对编码器分支特征 **裁剪**，保证与解码器上采样后张量尺寸一致。

---

## 6. 大图像推断：Overlap-Tile 与镜像外推

GPU 内存限制单次前向的分辨率。论文采用：

- **重叠平铺（overlap-tile）**：将大图切成相互重叠的图块依次预测，再拼成 **无缝** 分割结果；需选取图块尺寸，使各层 **2×2 池化** 在 x、y 上均作用于 **偶数** 尺寸（避免平铺 artifact）。
- **边界上下文**：预测靠近图像边界的区域时，缺失的上下文通过对输入做 **镜像外推** 补足（见图 2 示意：黄区预测依赖蓝区输入，外推部分用镜像填充）。

---

## 7. 与 FCN 的关系（论文自述）

- **相同点**：均由收缩网络 + 上采样支路构成端到端分割，替代逐 patch 分类。
- **U-Net 的改动**：更对称的解码器、更丰富的解码器通道、skip 上的 **复制—裁剪—拼接**；面向 **极少标注** 与 **生物医学** 精度需求做了工程化设计（见《U-Net-Influence.md》中历史与影响部分）。

---

## 8. 小结（结构一句话）

**U-Net = 收缩路径（池化下采样 + 通道加倍）+ 对称扩展路径（上采样/上卷积 + skip 拼接 + 卷积细化）+ 1×1 分类头**，全卷积、U 形连接，并配合 **平铺推断** 与 **镜像边界** 处理任意大尺寸图像。


## 关键设计细节

### 1. 无填充卷积（Valid Convolution）
- 所有卷积层均不进行填充。这意味着每次卷积后特征图尺寸会略微缩小。
- 输出分割图仅包含输入图像中那些具有完整上下文的像素。

### 2. 重叠平铺策略（Overlap-tile Strategy）
- 为了对任意大的图像进行无缝分割，且不受限于 GPU 内存，输入图像被分割成多个图块（tiles）进行处理。
- 预测图块边缘区域时，需要该区域周围更多的上下文。因此，网络会输入比预测区域更大的图块。
- 对于输入图像边界附近缺失的上下文，通过**镜像（mirroring）** 输入图像进行外推填充。

### 3. 通道数设计
- 收缩路径：通道数递增（64 -> 128 -> 256 -> 512 -> 1024），以学习更抽象的特征。
- 扩展路径：通道数递减（1024 -> 512 -> 256 -> 128 -> 64），逐步恢复空间细节。
- 最终输出层：通道数等于类别数（K）。

## 架构参数示例（以最低分辨率 32x32 为例）

- **输入**：572x572 单通道图像。
- **收缩路径**：经过 5 次下采样，特征图尺寸从 572x572 逐步降至 28x28（考虑卷积边界损失）。
- **扩展路径**：经过 4 次上采样，特征图尺寸逐步恢复至 388x388。
- **输出**：388x388 的多通道分割图（K 个通道，每个通道对应一个类别的概率）。

## 训练与损失函数

- **损失函数**：结合了逐像素 Soft-max 激活函数的交叉熵损失。
- **权重图**：引入了一个预计算的权重图，用于：
    1.  补偿训练数据中不同类别的像素频率差异。
    2.  强制网络学习相互接触物体之间的小分隔边界（通过给边界像素更高的权重）。
- **优化器**：随机梯度下降（SGD），使用高动量（0.99）。
- **权重初始化**：从标准差为 √(2/N) 的高斯分布中初始化权重，其中 N 是每个神经元的输入节点数（He 初始化）。

## 数据增强

由于训练数据极其有限，论文提出了一种**强大的数据增强策略**，特别是：
- **随机弹性形变（Random Elastic Deformations）**：通过在粗糙网格上生成随机位移向量，然后进行插值来模拟真实的组织形变。这被认为是网络在少量标注样本下仍能表现出色的关键。
- 其他增强包括平移、旋转、缩放和灰度值变化。
- 在收缩路径末端使用 **Dropout** 进行隐式增强。

## 总结

U-Net 的核心架构创新在于：
1.  **U形对称结构**：将编码器和解码器对称连接，形成清晰的语义层级。
2.  **跳跃连接**：通过拼接操作，将高分辨率的空间细节与高语义的上下文信息融合，实现了精准的像素级定位。
3.  **无全连接层**：保持了空间信息，使其成为全卷积网络在分割任务上的优雅实现。
4.  **针对小样本设计的增强策略**：通过弹性形变等，解决了生物医学图像标注成本高的痛点。
