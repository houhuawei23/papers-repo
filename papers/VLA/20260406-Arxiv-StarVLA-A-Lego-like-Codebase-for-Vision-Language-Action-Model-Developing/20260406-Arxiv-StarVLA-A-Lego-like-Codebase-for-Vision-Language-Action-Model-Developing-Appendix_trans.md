##### 贡献者政策（Contributor Policy）。

 **作者（Authors）**  构成了 StarVLA 的核心团队。该团队负责持续迭代核心功能、维护基础框架，并为项目提供持续、长期的支持。我们强烈鼓励有兴趣做出持续、结构性贡献并希望加入核心作者团队的研究人员和开发者与我们联系。 **社区贡献者（Community Contributors）**  是项目更广泛生态系统背后的重要力量。我们持续收到来自开源社区的宝贵支持——从新功能实现（拉取请求，pull requests）和错误修复（bug fixes）到建设性反馈。我们深表感激这些努力，它们使 StarVLA 得以快速发展。完整且持续更新的贡献者历史记录维护于 [starvla.github.io/contributors](https://starvla.github.io/contributors/)。
